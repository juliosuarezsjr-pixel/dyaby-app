DYABY — ARQUIVOS COMPLETOS PARA INSTALAÇÃO

Conteúdo:
- server.js
- index.html
- package.json
- .env.example

ATENÇÃO:
1. Estes arquivos são uma base funcional do backend/frontend e não significam que o aplicativo já está pronto para produção.
2. O backend usa PostgreSQL. No Render, configure DATABASE_URL apontando para o PostgreSQL.
3. Configure JWT_SECRET, ADMIN_EMAIL e ADMIN_PASSWORD como Environment Variables no Render.
4. Nunca coloque senhas ou tokens reais dentro do código.
5. O login de passageiro não usa WhatsApp OTP.
6. A verificação por WhatsApp do motorista/entregador ainda precisa ser conectada a um provedor como Twilio Verify.
7. O sistema de mulheres já possui regra no backend:
   - corrida normal: pode aparecer para motoristas ativos;
   - corrida somente para mulheres: só aparece/é aceita por motorista com gender=female;
   - motorista mulher pode escolher "todas" ou "somente mulheres";
   - motorista homem não pode selecionar "somente mulheres".
8. A compensação de R$5 por cancelamento do passageiro após 3 minutos de corrida iniciada está no backend.
9. Mapas, Pix, pagamentos, chat em tempo real, entregas e aprovação documental precisam de integrações adicionais antes de uso comercial.
10. Depois de substituir os arquivos no GitHub, faça novo deploy no Render.

COMO INSTALAR NO GITHUB:
- Abra o repositório dyaby-app.
- Substitua server.js, index.html e package.json pelos arquivos deste pacote.
- Adicione .env.example apenas como referência; não coloque valores reais nele.
- Faça commit.

COMO CONFIGURAR NO RENDER:
- Build Command: npm install
- Start Command: npm start
- Root Directory: deixe vazio se estes arquivos estiverem na raiz.
- Environment:
  DATABASE_URL = URL do PostgreSQL
  JWT_SECRET = segredo longo
  ADMIN_EMAIL = e-mail do administrador
  ADMIN_PASSWORD = senha do administrador

Antes de publicar para clientes, faça testes de cadastro, login, corrida normal, corrida para mulheres, aprovação de motorista e cancelamento.
