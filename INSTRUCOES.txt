DYABY V2.3 - CORREÇÃO DE ERROS 502

Arquivos: server.js, index.html, package.json

Nesta versão:
- endpoints administrativos passam por tratamento de erros assíncronos;
- erros de banco não derrubam o processo durante uma chamada administrativa;
- solicitação de corrida também recebe tratamento de erro;
- o frontend mantém a mensagem HTTP real para diagnóstico;
- se o token administrativo expirar, o painel volta ao login.

Depois de enviar os arquivos para o GitHub/main e o Render concluir o deploy, faça um novo login em /admin.

Variáveis necessárias no Render:
DATABASE_URL
JWT_SECRET
ADMIN_EMAIL
ADMIN_PASSWORD

Não coloque esses valores no GitHub nem envie os segredos pelo chat.
